# Адаптивные изображения (наследие КР №3)

В проекте сохранены используемые файлы изображений:

- `hero-bg-480.jpg`, `hero-bg-800.jpg`, `hero-bg-1308.jpg` — фон главной страницы под разные ширины экрана; пути указаны в `css/responsive.css`.
- `redbull-480.jpg`, `redbull-640.jpg`, `redbull-739.jpg` — резервные JPEG.
- `redbull-480.webp`, `redbull-640.webp`, `redbull-739.webp` — WebP-варианты, выбираются через `<picture>` и `srcset` в `product.html`.

Неиспользуемые исходные `hero-bg.jpg` и `redbull.jpg` исключены из итогового ZIP для уменьшения объёма. Оригинальные кадры можно восстановить из КР №3.
