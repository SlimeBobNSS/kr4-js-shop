В режиме группировки на странице **«Билеты»** все 12 вариантов разделены на три визуальных блока: **Гран-при Лас-Вегаса**, **Гран-при Катара** и **Гран-при Абу-Даби**. ## Закрытие пунктов практических №15–17

### Практическая №15 — функции и безопасный вывод

В `js/main.js` отдельно реализованы `formatPrice(price)`, `calculateDiscount(price, discountPercent)`, `calculateFinalPrice(price, discountPercent)`, `getProductStatus(product)` и `createProductSummary(product)`. Прежние функции интерфейса `getDiscountPrice`, `getAvailabilityLabel`, `getShortDescription` оставлены для совместимости с карточками и корзиной. Функция итоговой цены использует функцию расчёта скидки, как в методичке. На `lab.html` можно увидеть их вызовы, объект первого товара, `console.table()` и результаты в консоли.

Для пользовательских данных используется `textContent`: браузер воспринимает строку как текст, не разбирая её как HTML. Использование `innerHTML` с содержимым поля формы, `localStorage` или внешнего API потенциально привело бы к выполнению нежелательной HTML-разметки/скриптов. Элементы карточек создаются через `document.createElement()` и добавляются через `append()`.

### Практическая №16 — массив и расчёты

В `js/main.js` доступны функции с названиями из методички:

- `getProductTitles(productList)` — `map`, отдельный массив названий;
- `getAvailableProducts(productList)` — `filter`, только доступные товары;
- `searchProducts(productList, query)` — поиск по названию без учёта регистра;
- `filterProductsByCategory(productList, category)` — отбор по категории;
- `sortProductsByPrice(productList, direction)` — сортировка **копии** массива по исходной цене;
- `findProductById(productList, id)` — поиск по `id`;
- `calculateTotalPrice(productList)` — общая стоимость через `reduce`;
- `countAvailableProducts(productList)` — подсчёт доступных товаров через `for...of`;
- `calculateAveragePrice(productList)` — средняя исходная цена (с защитой от пустого массива) через `for`;
- `prepareProducts(productList, query, category, direction)` — последовательный поиск, фильтр и сортировка.

**Различие двух расчётов цены:** методическая `sortProductsByPrice()` сортирует по `price` исходного объекта; интерфейс билетов сортирует по текущей цене с учётом скидки (`getDiscountPrice()`) — так покупатель видит правильный порядок **отображаемых** цен. Счётчик корзины и итоговая сумма использует `reduce` с учётом количества. В массиве товаров дополнительно присутствует учебный `rating` (данные не отражают реальных отзывов).

На `catalog.html` и `order.html` статистика «Всего билетов / В наличии / Средняя цена» формируется из массива `products` и записывается через `textContent`. Для полной учебной демонстрации открыть `lab.html` с Console: там выводится массив названий, отфильтрованные товары, минимальная и средняя цены, поиск по `id` и комбинация фильтров.

### Практическая №17 — DOM, события и заявка

На `catalog.html` помимо пилотов теперь есть **полный интерактивный каталог тех же 12 билетов**, что и на `order.html`. Оба каталога работают на одной функции `initTicketCatalog(form)`, используют `createProductCard()`, `renderProducts()`, события `input`, `change`, `reset`, `click` и делегирование. Перерисовка выполняется через `replaceChildren()`, безопасный вывод — через `textContent()`. При нуле результатов показывается отдельный текст, а счётчик отображает количество.

На `order.html` добавлена **форма запроса на подбор билета** (`#ticket-request-form`): имя, e-mail, телефон и согласие. `validation.js` проверяет пустые поля и формат, выводит сообщения рядом с полями и предотвращает отправку через `preventDefault()`. Если проверка пройдена, поля очищаются и выводится сообщение об имитации отправки. Реальная отправка на сервер не выполняется. Основное оформление выбранных билетов с расчётом стоимости по-прежнему находится в `cart.html`. Для полей формы корзины добавлены связи `aria-describedby` с текстами ошибок.

### Как продемонстрировать Console и Breakpoints

1. Откройте `lab.html` и нажмите `F12` → **Console**: при загрузке появляются объект товара, `console.table()`, результаты всех названных функций и итоговая статистика.

4. Пример цикла `for` находится в `calculateAveragePrice()`, цикл `for...of` — в `countAvailableProducts()`. Методы `map`, `filter`, `find`, `sort`, `reduce`, `forEach` используются в других функциях сайта.

### Важно: Git и сдача в СДО

Архив ZIP **не содержит историю Git**, а создать задним числом правдивые коммиты, GitHub Pull Request или отправить работу в СДО из офлайн-архива нельзя. После распаковки используйте в терминале из папки `kr4-js-shop`:

```bash
git init
git branch -M main
git add .
git commit -m "feat: complete KR4 JavaScript shop with practice 15-18 requirements"
```

Затем создайте **свой** отдельный репозиторий `kr4-js-shop` на GitHub, добавьте remote по адресу, который GitHub выдаст для вашего репозитория, и выполните `git push -u origin main`. Дальнейшие изменения можно делать в ветках `feature/products-array` и `feature/dom-events` с настоящими коммитами и PR. Для сдачи в СДО вставьте ссылку на **реальный** созданный репозиторий.

> Учебная лаборатория и тестовые `rating` не означают, что контрольная работа прошла оценку преподавателя. Скриншоты Lighthouse в архиве относятся к КР №3; перед сдачей рекомендуется сделать актуальную проверку опубликованного сайта.
